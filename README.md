# EPS Sales Dashboard (Prototype)

Interactive single-file dashboard for the EPS (Pumps & Compressors) division — Siamraj Public Company Limited.

**Purpose:** presentation prototype of the 5-role sales dashboard (Sales Rep / Sales Group Head / Product Manager / BU Manager / CEO).

**Contents:** `index.html` — self-contained (HTML + CSS + JS + Chart.js via CDN). Open locally in a browser.

> ⚠️ Numbers and personnel shown in the prototype are illustrative/demo data for presentation purposes; the structure follows the real CRM data model (vtiger). Internal analysis documents are kept in the company workspace, not in this repo.
